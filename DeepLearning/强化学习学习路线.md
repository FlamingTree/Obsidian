**学习路线**
- `传统强化学习基础`：先理解 MDP、策略梯度、Actor-Critic、PPO。
- `LLM 对齐基础`：理解 SFT、Reward Model、RLHF。
- `偏好优化方法`：重点看 DPO、IPO、KTO、ORPO。
- `推理类 RL`：了解 RLVR、GRPO、RLAIF、可验证奖励。
- `工程实现`：看 TRL、OpenRLHF、verl、DeepSpeed-Chat 等项目。

---

**书籍推荐**
- `Reinforcement Learning: An Introduction`，Richard S. Sutton / Andrew G. Barto  
  强化学习经典教材，适合理解 MDP、价值函数、策略梯度、Actor-Critic。  
  官网：[http://incompleteideas.net/book/the-book-2nd.html](http://incompleteideas.net/book/the-book-2nd.html)

- `Deep Reinforcement Learning Hands-On`，Maxim Lapan  
  更偏工程实践，适合理解 DQN、A2C、PPO 等算法怎么写代码。

- `Algorithms for Reinforcement Learning`，Csaba Szepesvári  
  数学更紧凑，适合想系统理解 RL 理论的人。  
  PDF：[https://sites.ualberta.ca/~szepesva/rlbook.html](https://sites.ualberta.ca/~szepesva/rlbook.html)

- `Hands-On Large Language Models`，Jay Alammar / Maarten Grootendorst  
  偏 LLM 全流程入门，不是专门讲 RL，但对 Embedding、Transformer、LLM 应用、对齐有帮助。

- `Build a Large Language Model From Scratch`，Sebastian Raschka  
  更偏从零实现 LLM，对理解 SFT、生成、loss、token-level 训练有帮助。RLHF 不是主线，但适合作为 LLM 基础书。

**LLM RLHF 核心文章**
- `Training language models to follow instructions with human feedback`，InstructGPT  
  RLHF 经典论文，讲清楚 `SFT -> Reward Model -> PPO` 这条主线。  
  链接：[https://arxiv.org/abs/2203.02155](https://arxiv.org/abs/2203.02155)

- `Learning to summarize from human feedback`  
  早期 RLHF 代表作，用人类偏好训练摘要模型。  
  链接：[https://arxiv.org/abs/2009.01325](https://arxiv.org/abs/2009.01325)

- `Constitutional AI: Harmlessness from AI Feedback`  
  介绍 RLAIF，用 AI 反馈替代部分人类反馈。  
  链接：[https://arxiv.org/abs/2212.08073](https://arxiv.org/abs/2212.08073)

- `Training a Helpful and Harmless Assistant with Reinforcement Learning from Human Feedback`，Anthropic  
  讲 helpful/harmless 对齐，非常适合理解偏好数据和奖励模型。  
  链接：[https://arxiv.org/abs/2204.05862](https://arxiv.org/abs/2204.05862)

---

**DPO/偏好优化文章**
- `Direct Preference Optimization: Your Language Model is Secretly a Reward Model`  
  DPO 核心论文，非常重要。DPO 绕过显式 Reward Model 和 PPO，直接用 chosen/rejected 偏好对训练。  
  链接：[https://arxiv.org/abs/2305.18290](https://arxiv.org/abs/2305.18290)

- `IPO: A General Theoretical Paradigm to Understand Learning from Human Preferences`  
  从理论角度分析偏好优化，适合看完 DPO 后继续深入。  
  链接：[https://arxiv.org/abs/2310.12036](https://arxiv.org/abs/2310.12036)

- `KTO: Model Alignment as Prospect Theoretic Optimization`  
  不要求严格 chosen/rejected 成对数据，可以用 desirable/undesirable 数据。  
  链接：[https://arxiv.org/abs/2402.01306](https://arxiv.org/abs/2402.01306)

- `ORPO: Monolithic Preference Optimization without Reference Model`  
  不使用 reference model 的偏好优化方法。  
  链接：[https://arxiv.org/abs/2403.07691](https://arxiv.org/abs/2403.07691)

- `A Survey of Reinforcement Learning from Human Feedback`  
  综述类文章，适合系统了解 RLHF。  
  链接：[https://arxiv.org/abs/2312.14925](https://arxiv.org/abs/2312.14925)

**PPO/RLHF 工程文章**
- `The N+ Implementation Details of RLHF with PPO`  
  非常推荐，讲 RLHF + PPO 的大量工程细节。  
  链接：[https://huggingface.co/blog/the_n_implementation_details_of_rlhf_with_ppo](https://huggingface.co/blog/the_n_implementation_details_of_rlhf_with_ppo)

- `Illustrating Reinforcement Learning from Human Feedback`，Hugging Face

  链接：[https://huggingface.co/blog/rlhf](https://huggingface.co/blog/rlhf)

- `DeepSpeed-Chat: Easy, Fast and Affordable RLHF Training`  
  微软的 RLHF 工程实践，适合理解大规模训练流程。  
  链接：[https://github.com/microsoft/DeepSpeedExamples/tree/master/applications/DeepSpeed-Chat](https://github.com/microsoft/DeepSpeedExamples/tree/master/applications/DeepSpeed-Chat)

- `OpenRLHF`  
  开源 RLHF 框架，支持 PPO、DPO、Reward Model 等。  
  链接：[https://github.com/OpenRLHF/OpenRLHF](https://github.com/OpenRLHF/OpenRLHF)

- `TRL: Transformer Reinforcement Learning`  
  Hugging Face 的 RLHF/偏好优化库，适合看 DPOTrainer、PPOTrainer 实现。  
  链接：[https://github.com/huggingface/trl](https://github.com/huggingface/trl)

**推理模型/RLVR/GRPO**
- `DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models`  
  介绍数学推理模型中的 GRPO，适合理解不依赖传统 value model 的 RL 方法。  
  链接：[https://arxiv.org/abs/2402.03300](https://arxiv.org/abs/2402.03300)

- `DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning`  
  了解现代推理模型如何通过 RL 激发长链推理能力。  
  链接：[https://arxiv.org/abs/2501.12948](https://arxiv.org/abs/2501.12948)

- `verl`  
  字节/社区常用的大模型 RL 训练框架，适合看 PPO、GRPO、RLVR 工程实现。  
  链接：[https://github.com/volcengine/verl](https://github.com/volcengine/verl)

**建议阅读顺序**
- `第一阶段`：看 Sutton 书前几章，理解 state/action/reward、policy、value、advantage。
- `第二阶段`：看 Spinning Up 的 Policy Gradient、Actor-Critic、PPO。
- `第三阶段`：看 InstructGPT 和 Hugging Face RLHF 图文文章。
- `第四阶段`：看 DPO 论文，再对照 TRL 的 `DPOTrainer` 实现。
- `第五阶段`：看 The N+ Implementation Details of RLHF with PPO，理解 PPO-RLHF 工程细节。
- `第六阶段`：看 DeepSeekMath / DeepSeek-R1 / verl，理解推理模型中的 RLVR 和 GRPO。

**如果只选 5 个**
- `Sutton RL Book`：打强化学习基础。
- `OpenAI Spinning Up`：理解 PPO/Actor-Critic。
- `InstructGPT paper`：理解 RLHF 标准流程。
- `DPO paper`：理解当前常用偏好优化。
- `TRL / OpenRLHF / verl`：看真实工程实现。
